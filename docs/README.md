## Reading the pages

- **Decided:** settled.
- **Proposed:** a suggested answer, often a starting number for balancing. Expect it to change in play.
- **Open:** not decided yet.

Module art is in [`design/art/`](design/art/). Each image is an SVG drawn from simple isometric prisms, matching the look planned for the game.

## Prototype

[`prototypes/space-view.html`](prototypes/space-view.html) is a throwaway 3D sketch made while exploring the look. It shows the platform against a procedural nebula with mining ships and a freighter coming and going. Open it in a browser: drag to rotate, scroll to zoom. It loads three.js from a CDN, so it needs an internet connection.
